title: iPad / iPhone
---
iPad / iPhone のペアレンタルコントロールは「スクリーンタイム」という機能でまとめて設定します。

:::message
以前は「Apple ID」と呼ばれていたものが、現在は「**Apple Account**」という名称に変わっています。お手元の画面や、少し古い解説記事では「Apple ID」と書かれていることがありますが、同じものだと考えてください。
:::

## どんなことができる？
ざっくりですが、以下のようなことができます。

- 1日に使う時間を制限する（アプリごと・カテゴリごとにも設定できます）
- 夜間など、使えない時間帯を決める
- 利用するアプリや閲覧できるwebサイトを制限する
- App Storeでの購入やアプリのインストール・削除を制限する
- 連絡を取れる相手を制限する
- 年齢に合わない映画・音楽・アプリなどを制限する
- SiriやApple Intelligence（AI機能）の使用を制限する
- 位置情報や連絡先など、プライバシー設定の変更を禁止する

## 必要なもの
### ファミリー共有とお子様用のApple Account
現在のAppleの案内では、**保護者のデバイスで「ファミリー共有」を設定し、そこにお子様のApple Accountを追加する**、という形が基本になっています。この形にしておくと、保護者が自分のiPhoneやiPadから、お子様のデバイスの設定を遠隔で管理できます。

13歳未満のお子様は自分でApple Accountを作れませんので、保護者が作成します。作成は保護者のデバイスの「設定」＞「ファミリー」＞メンバーの追加＞「お子様用アカウントを作成」から行います。

https://support.apple.com/ja-jp/102617

:::message
お子様のメールアドレスがなくても大丈夫です。作成の途中で提案される `@icloud.com` のアドレスや、Game Centerのニックネームを使うこともできます。

なお、**生年月日は必ず正しく入力してください**。年齢に応じて自動的にオンになる保護機能があるためです。
:::

### 保護者がApple製のデバイスを持っていない場合
ファミリー共有が使えない場合でも、13〜17歳のお子様がご自分のiPhone / iPadをお持ちであれば、お子様がApple Accountを作成したあとに、**お子様のデバイス上で**保護者がスクリーンタイムとペアレンタルコントロールを設定・管理できます。

ただしこの場合、保護者の手元から遠隔で確認・変更することはできません。

### スクリーンタイム・パスコード
設定を勝手に変更されないようにするための4桁のパスコードです。これを設定しないと、お子様が設定画面から制限を解除できてしまいます。**必ず設定してください。**

お子様の誕生日や、デバイスのロック解除に使っている番号と同じものは避けましょう。

## 設定の入り口
保護者のデバイスから設定する場合の入り口は、常にここです。

1. 「設定」アプリを開いて下にスクロールし、「**スクリーンタイム**」をタップ
2. 「**ファミリー**」でお子様の名前をタップ

以降の設定はすべてこの画面から進みます。迷ったらここに戻ってきてください。

## 主な設定項目
### 使用できる時間を決める
| 項目 | 内容 |
| --- | --- |
| 休止時間 | 特定の時間帯にアプリと通知をブロックします。この時間帯は、電話と許可したアプリしか使えなくなります |
| App使用時間の制限 | 「ゲーム」「SNS」といったカテゴリ単位や、個々のアプリ単位で1日の使用時間の上限を決めます |
| 常に許可 | 休止時間中でも使えるアプリを指定します |
| 画面との距離 | 画面に顔を近づけすぎているときに、離すよう促すメッセージを表示します（眼精疲労の軽減） |

### やり取りする相手を制限する
| 項目 | 内容 |
| --- | --- |
| コミュニケーションの制限 | 電話、FaceTime、メッセージなどでやり取りできる相手を指定します。使うにはiCloudの連絡先を有効にしておく必要があります |
| コミュニケーションの安全性 | センシティブな写真やビデオを送受信しそうになったときに、お子様に確認を促します。写真の判定はデバイス内で行われ、Appleは中身にアクセスしません |

なお、どのような制限を設定しても、**緊急連絡先番号への通話は常に許可されます**。

### コンテンツとプライバシーの制限
アプリやwebサイト、購入まわりの制限は、すべてこの中にまとまっています。

まずこのスイッチをオンにするところから始めます。

1. 「設定」＞「スクリーンタイム」＞「ファミリー」でお子様の名前をタップ
2. 「**コンテンツとプライバシーの制限**」をタップ
3. スクリーンタイムのパスコードを入力し、スイッチをオンにする

オンにすると、以下の項目が設定できるようになります。

| 項目 | 何を制限できるか |
| --- | --- |
| iTunesおよびApp Storeでの購入 | アプリのインストール・削除、アプリ内課金の可否。購入時にパスワードを毎回要求するかどうかもここで決めます |
| 許可されたアプリと機能 | Apple標準のアプリ（メール、Safariなど）を使えるようにするかどうか。オフにしてもアプリが削除されるわけではなく、ホーム画面から見えなくなるだけです |
| App Store、メディア、Web、およびゲーム | 音楽・映画・テレビ番組・ブック・アプリの年齢レートの制限、webサイトの制限、Game Centerの制限 |
| IntelligenceとSiri | 画像生成、作文ツール、Siriと音声入力、Web検索コンテンツ、不適切な言葉などの制限 |
| プライバシー | 位置情報サービス、連絡先、写真、マイクなどへのアプリのアクセス設定を、変更できないよう固定します |
| 変更を許可 | パスコードとFace ID、アカウント、モバイルデータ通信、音量設定などの変更の可否 |

### webサイトの制限
よく使う設定なので個別に補足します。

「コンテンツとプライバシーの制限」＞「App Store、メディア、Web、およびゲーム」＞「**Webコンテンツ**」で、次の3つから選びます。

- **制限なし** … 制限しません
- **成人向けWebサイトを制限** … 不適切と判定されたサイトを自動的にブロックします。個別にブロックするサイト・許可するサイトを追加することもできます
- **許可されたWebサイトのみ** … 指定したサイト以外はすべて見られません

小さいお子様には「許可されたWebサイトのみ」、ある程度の年齢からは「成人向けWebサイトを制限」、というのが選び方の目安です。

## 例外のリクエスト
iOS 26 / iPadOS 26 以降では、設定した上限に達したときに、お子様から**例外をリクエスト**できるようになっています。リクエストは保護者のメッセージアプリに届き、その場で許可・却下を選べます。

「宿題であと10分だけ調べ物をしたい」といった場面で、いちいち設定画面を開かずに対応できるので便利です。

リクエストが届かない場合は、以下を確認してください。

- 保護者・お子様の両方のデバイスが最新のソフトウェアになっているか
- 保護者のApple AccountのメールアドレスでiMessageが使える状態になっているか
- 過去30日以内にiMessageでのやり取りをしているか
- メッセージアプリの通知がオンになっているか

## つまずきやすいポイント
### すべてのデバイスを最新にしておく
ファミリー共有グループ内のデバイスのバージョンがバラバラだと、設定が正しく同期されないことがあります。設定を変更する前に、保護者・お子様の両方のデバイスをアップデートしておいてください。

### 一部の設定は最初からオンになっている
お子様の年齢や、お住まいの国・地域によって、いくつかのペアレンタルコントロールは初期状態でオンになっています。「設定した覚えがないのに制限されている」という場合はこれが理由です。

### 「コンテンツとプライバシーの制限」をオフにすると全部止まる
このスイッチをオフにすると、その中で設定した内容がまとめて一時停止します。個別の設定が消えるわけではなく、再びオンにすれば元に戻ります。
