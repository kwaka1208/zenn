## ペアレンタルコントロールとは

「ペアレンタルコントロール」とは、子どもたちがPCやスマートフォン、ゲーム機を安全かつ適切な時間に使えるようにするためのもので、利用できるアプリや利用できる時間（時間帯や時間の長さ）などを保護者が設定する機能です。

「子どもたちがデジタルデバイスを使うことを制限する」ためのものではなく「積極的かつ適切に使えるようにする機能」ですので、子どもたちとも話し合った上で使っていきましょう。

## この本の読み方

第2章以降は、機器ごとに独立した章になっています。お使いの機器の章だけを読んでいただければ大丈夫です。

- ニンテンドースイッチ
- iPad / iPhone
- Chromebook / Android
- Mac
- Windows

各章は次の構成で統一しています。

| 見出し | 内容 |
| --- | --- |
| どんなことができる？ | その機器で設定できることの一覧 |
| 必要なもの | 設定を始める前に用意しておくもの |
| 設定の入り口 | どのアプリの、どこを開けばいいのか |
| 主な設定項目 | 各項目が何を制限するのか |
| つまずきやすいポイント | 先に知っておくと事故を防げること |

最後の「おまけ」の章には、機器を問わず共通する話（設定をすり抜ける「抜け道」への向き合い方や、子どもとのルールづくり）をまとめています。どの機器をお使いの方にも読んでいただきたい内容です。

## 情報の鮮度について

画面や操作方法はOSのバージョンによって変わります。この本では、**変わりにくい情報**（用意するもの、設定の入り口、設定項目の名前と意味、つまずきやすいポイント）を本文に書き、**変わりやすい情報**（1タップずつの手順や画面写真）は公式サイトへのリンクに委ねる、という方針をとっています。

ですので、まず本文で全体像とハマりどころをつかんでいただき、細かい画面の操作で迷ったときにリンク先を開く、という使い方をおすすめします。

なお、本文中の設定項目名は執筆時点（2026年8月）のものです。お手元の画面と名前が違う場合は、似た名前の項目を探してみてください。項目の名前が変わっても、できること自体はあまり変わりません。

## 大前提として

ペアレンタルコントロールは**万能ではありません**。どの機器の機能にも、意図せず設定をすり抜けてしまう「抜け道」があります。この本ではそれぞれの章で具体的に触れていますが、抜け道を完全にふさぐことはできない、という前提で使ってください。

設定は「子どもを閉じ込める壁」ではなく「うっかり危ないところへ行かないためのガードレール」だと考えて、**設定と会話をセットで**運用するのが現実的です。
