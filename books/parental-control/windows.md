title: Windows
---
Windowsのペアレンタルコントロールは「**Microsoft Family Safety**（マイクロソフト ファミリー セーフティ）」という仕組みで設定します。

Windowsだけでなく、**Xbox や Android スマートフォンにも同じ設定が効く**のが特徴です。

## どんなことができる？
ざっくりですが、以下のようなことができます。

- 1日に使う時間を制限する（デバイス単位・アプリ単位のどちらでも設定できます）
- アプリやゲームの利用を制限する
- 閲覧できるwebサイトや検索結果を制限する
- アプリやゲームの利用状況をレポートで確認する
- アプリの購入や支払い金額を制限する
- 制限に達したときに、お子様から延長のリクエストを受け取る

## 必要なもの
### 保護者と子どものMicrosoftアカウント
保護者・お子様ともにMicrosoftアカウント（無料）が必要です。お子様のアカウントは、保護者が「ファミリーグループ」に追加する形で作成します。

ファミリーグループの管理者は「家族の代表者」と呼ばれ、メンバーの追加・削除、制限の管理、アクティビティレポートの閲覧ができます。

### Windows内の子ども用ユーザーアカウント
Windowsにお子様用のユーザーアカウントが必要です。PCを家族で共用する場合、共用するのはハードウェアであって、同じユーザーアカウントを共用するものではありません。

保護者のアカウントを一緒に使ってしまうと、使用時間の集計が保護者の分と混ざってしまい、制限が正しく働きません。

### スマートフォンアプリ（任意）
必須ではありませんが、「Microsoft Family Safety」アプリを入れておくと、外出先からでもリクエストへの応答や設定変更ができて便利です。Android版・iPhone版の両方があります。

## 設定の入り口
Windowsの設定画面とwebブラウザを行き来することになります。ここが少しわかりにくいところです。

**1. お子様のアカウントを追加する（Windows側）**

保護者のアカウントでWindowsにサインインし、「設定」＞「アカウント」＞「家族とその他のユーザー」＞「**家族のメンバーを追加**」と進み、お子様のメールアドレスを入力してアカウントを作成します。

**2. 制限を設定する（web側）**

実際の制限は、ブラウザで開く管理ページか、スマートフォンアプリで設定します。Windowsの設定画面にある「オンラインで家族の設定を管理」のリンクからも開けます。

https://account.microsoft.com/family/

## 主な設定項目
| 項目 | 内容 |
| --- | --- |
| 使用時間 | デバイスを使える時間の上限や時間帯を、曜日ごとに細かく設定できます |
| アプリとゲームの制限 | インストール済みのアプリごとに、使用の可否や1日の利用時間を設定します |
| コンテンツフィルター（アプリとゲーム） | 年齢に応じて、適さないアプリやゲームをブロックします |
| コンテンツフィルター（Webと検索） | 成人向けサイトや年齢に不適切なwebサイトをブロックし、検索結果もフィルタします |
| 支出 | Microsoftアカウントに入金しておき、その範囲内で購入させます。購入時に保護者の承認を必要にしたり、購入があったときにメールで通知を受け取ったりもできます |
| アクティビティレポート | どのアプリやサイトをどれだけ使ったかを、定期的に確認できます |

「支出」の仕組みは、クレジットカードを子どもに触らせずに、あらかじめ決めた金額の範囲でだけ買い物ができる、というものです。金銭感覚を育てる練習にも使えます。

## つまずきやすいポイント
### Webフィルターは Microsoft Edge でしか効きません
**これがWindowsで一番重要な注意点です。**

「Webと検索のコンテンツフィルター」が機能するのは、**Microsoft Edge を使っているときだけ**です。

そのため、この機能をオンにすると、Chrome や Firefox など**よく使われる他のブラウザは自動的にブロックされます**。フィルターをすり抜けられてしまうためです。

つまり、Webの制限をかけるなら「お子様のアカウントではEdgeを使う」ことが前提になります。普段Chromeをお使いのご家庭では、ここで戸惑うかもしれません。**制限をかける前に、お子様に理由を説明しておく**ことをおすすめします。

### 対応しているデバイスを確認しておく
画面の使用時間の制限が働くのは、Windows 10 / Windows 11、Xbox（Xbox One、Xbox Series X / S）、そして Android のアプリとゲームです。

**iPhone や iPad には使用時間の制限が効きません。** お子様がiPhoneをお使いの場合は、「iPad / iPhone」の章のスクリーンタイムを併用してください。

### 延長のリクエストに応える運用を決めておく
制限時間に達したとき、お子様から時間延長やアプリ・サイトの許可をリクエストできます。保護者はその都度、許可するかどうかを選べます。

便利な機能ですが、「宿題だから」と言われるたびに毎回許可していると制限の意味がなくなります。**どういうときなら延長するのか**を、あらかじめお子様と話し合って決めておくとお互いに楽です。
