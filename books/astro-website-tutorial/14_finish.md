## このチュートリアルで学んだこと

### Astroの基礎

| 概念 | 内容 |
|---|---|
| **静的サイト生成** | ビルド時に全ページをHTMLとして生成する仕組み。速さの源 |
| **コンポーネントスクリプト** | `---` で挟まれた、ビルド時に実行されるコード |
| **コンポーネントとProps** | 再利用できる部品と、部品にデータを渡す仕組み |
| **レイアウトと `<slot />`** | ページの骨組みを共通化する仕組み |
| **ファイルベースルーティング** | `src/pages/` の構造がそのままURLになる |
| **動的ルーティング** | `[id].astro` ＋ `getStaticPaths()` で複数ページを自動生成 |
| **Content Collections** | Markdown記事をスキーマ付きで安全に管理する仕組み |
| **`astro:assets`** | `<Image />` による画像の自動最適化 |
| **`<script>` タグ** | ブラウザで動く処理を書く場所 |
| **アイランドアーキテクチャ** | 静的HTMLの中に、動く部分だけを小さく置く設計思想 |

### サイト設計の考え方

技術の使い方だけでなく、**壊れにくいサイトの作り方**も実践してきました。

- **情報は1か所にまとめる**：サイト名は `consts.ts`、色は CSS変数、タグは記事のfrontmatterから自動集計。「同じ情報を2か所に書きそうになったら共通化のサイン」でした
- **データと見た目を分ける**：ナビゲーションは配列データ＋`map()` で描画。項目の追加が1行で済みました
- **JavaScriptは必要な分だけ**：サイトのほぼ全体が静的HTMLで、ブラウザで動くのはダークモード切り替えの数行だけです

この考え方は、Astroに限らずどんなWeb制作でも役に立ちます。

## 次のステップ

サイトは完成しましたが、ここからが本当のスタートです。自分のサイトなので、自由に育てていきましょう。

### まずやってみてほしいこと

**記事を書く**
何より大切なのはこれです。`src/content/blog/` にMarkdownファイルを置いてpushするだけで公開されます。完璧なデザインより、続けられる更新です。

**デザインを自分色にする**
`global.css` のCSS変数を変えるだけで、サイトの印象は大きく変わります。フォントを [Google Fonts](https://fonts.google.com/) のものに変えてみるのも楽しいです。

### 機能追加のアイデア

**下書き機能**
スキーマに `draft: z.boolean().default(false)` を追加し、`getCollection()` で絞り込めば、「まだ公開しない記事」を管理できます。

```ts
const posts = await getCollection('blog', ({ data }) => !data.draft);
```

**ページネーション**
記事が増えてきたら、一覧を「1ページ10件」に分ける機能です。Astroには `paginate()` という専用の仕組みが用意されています。

**OGP画像の設定**
SNSでシェアされたときに表示される画像（OGP画像）を `<head>` に設定すると、シェアされたときの見栄えが良くなります。

**ページ遷移アニメーション**
AstroのView Transitions機能（`<ClientRouter />`）を使うと、ページの切り替えがふわっとしたアニメーションになります。

### さらに学ぶには

- **Astro公式ドキュメント**（[docs.astro.build](https://docs.astro.build/ja/)）：日本語版があり、チュートリアルも充実しています
- **UIフレームワークとの連携**：検索機能のような複雑な「島」が必要になったら、ReactやSvelteのコンポーネントをAstroに埋め込む方法を学んでみてください
- **独自ドメイン**：`ユーザー名.github.io` の代わりに、自分で取得したドメイン（`example.com` など）でサイトを公開することもできます

## おわりに

Astroの魅力は、「HTMLとCSSの知識がそのまま活きる」ことと、「コンテンツに集中できる」ことです。フレームワークの複雑さと格闘するのではなく、書きたいこと・見せたいものに時間を使えます。

このチュートリアルで作ったサイトは、これからあなたが何かを発信するたびに育っていく場所です。まずは1本、記事を書いてpushしてみてください。数分後には、それが世界中から読める状態になっています。

楽しいサイトづくりを！
