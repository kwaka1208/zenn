## `.astro` ファイルの構造

Astroのファイル（拡張子 `.astro`）は、大きく2つの部分に分かれています。

```html
---
// ① コンポーネントスクリプト（データの準備をする場所）
const name = "わかばやし";
---

<!-- ② テンプレート（HTMLを書く場所） -->
<h1>{name}のサイト</h1>
```

### ① コンポーネントスクリプト

ファイル先頭の `---` と `---` で挟まれた部分です。ここにはJavaScript（TypeScript）のコードを書けます。変数の定義、データの読み込みなど、**表示に使うデータの準備**をする場所です。

:::message
Zennの記事を書いたことがある方は、記事の先頭にある `---` で囲まれた部分（フロントマター）を思い出すかもしれません。見た目はそっくりですが、Astroのこの部分には設定ではなく**プログラムのコード**を書きます。
:::

**重要な性質**：この部分のコードは、**サイトを作る（ビルドする）ときに一度だけ実行され、訪問者のブラウザでは実行されません**。つまり、ここに何を書いてもページの表示速度には影響しないのです。これがAstroの速さの秘密です。

### ② テンプレート

2つ目の `---` より下の部分には、HTMLをそのまま書けます。さらに `{ }`（波かっこ）を使うと、①で用意した変数を埋め込めます。

```html
---
const name = "わかばやし";
const hobbies = ["カメラ", "登山", "コーヒー"];
---

<h1>{name}のサイト</h1>
<p>趣味は{hobbies.length}個あります。</p>
```

`{hobbies.length}` は「配列 `hobbies` の要素数」なので、「趣味は3個あります。」と表示されます。

### 繰り返し表示

配列のデータを繰り返して表示したいときは、`map()` を使います。

```html
---
const hobbies = ["カメラ", "登山", "コーヒー"];
---

<ul>
  {hobbies.map((hobby) => <li>{hobby}</li>)}
</ul>
```

`map()` は「配列の要素をひとつずつ取り出して、それぞれをHTMLに変換する」書き方です。表示結果は次のHTMLと同じになります。

```html
<ul>
  <li>カメラ</li>
  <li>登山</li>
  <li>コーヒー</li>
</ul>
```

「データを1か所（配列）にまとめておいて、表示は `map()` に任せる」のがAstroでの基本スタイルです。あとから趣味が増えても、配列に1行足すだけで表示に反映されます。

## コンポーネント：ページの部品を作る

サイトを作っていると、**同じ見た目のかたまりを何度も使いたい**場面が出てきます。たとえば「タイトルと説明文が入ったカード」を3つ並べたいとき、同じHTMLを3回コピーするのは大変ですし、あとで直すときに3か所直すことになります。

そこで登場するのが**コンポーネント**です。コンポーネントは「再利用できるページの部品」で、Astroでは `.astro` ファイルとして作ります。

### カードコンポーネントを作る

`src/components/` フォルダを新しく作り、その中に `Card.astro` というファイルを作ってください。

```html:src/components/Card.astro
---
interface Props {
  title: string;
  description: string;
}

const { title, description } = Astro.props;
---

<div class="card">
  <h2>{title}</h2>
  <p>{description}</p>
</div>

<style>
  .card {
    border: 1px solid #ccc;
    border-radius: 8px;
    padding: 1rem;
  }
</style>
```

新しい要素が3つ登場しました。順番に説明します。

### Props：コンポーネントにデータを渡す仕組み

**Props（プロップス）** は、コンポーネントを使う側から「表示する内容」を渡す仕組みです。

```ts
interface Props {
  title: string;
  description: string;
}
```

この `interface Props` は「このコンポーネントは `title` と `description` という2つの文字列（`string`）を受け取ります」という宣言です。これはTypeScriptの**型定義**という書き方で、渡し忘れや綴りミスがあるとエディタが教えてくれるようになります。

```ts
const { title, description } = Astro.props;
```

この行で、渡されたデータを受け取って変数として使えるようにしています。

### `<style>`：コンポーネント専用のスタイル

`.astro` ファイルの中に `<style>` タグを書くと、そのスタイルは**このコンポーネントの中だけに適用されます**。ここで `.card` にスタイルを書いても、他のファイルにたまたま同じ `class="card"` があっても影響しません。

「スタイルの影響範囲が部品の中に閉じている」ため、安心してスタイルを書けます。これはAstroの便利な特徴のひとつです。

## コンポーネントを使う

作った `Card.astro` をトップページで使ってみましょう。`src/pages/index.astro` を次のように書き換えてください。

```html:src/pages/index.astro
---
import Card from '../components/Card.astro';
---

<html lang="ja">
  <head>
    <meta charset="utf-8" />
    <title>わたしのサイト</title>
  </head>
  <body>
    <h1>わたしのサイト</h1>
    <p>ようこそ！</p>

    <Card title="カメラ" description="週末に風景写真を撮っています。" />
    <Card title="登山" description="低山めぐりが好きです。" />
    <Card title="コーヒー" description="自宅で豆を挽いています。" />
  </body>
</html>
```

ポイントは2つです。

1. **`import` で部品を読み込む**：コンポーネントスクリプト内で `import Card from '../components/Card.astro';` と書くと、`<Card />` というタグが使えるようになります。`../` は「ひとつ上のフォルダ」という意味です。
2. **HTMLの属性のようにPropsを渡す**：`title="カメラ"` のように書くと、その値がコンポーネントの `Astro.props` に届きます。

保存すると、枠線のついたカードが3つ並びます。同じ見た目の部品を、データだけ変えて再利用できました。

### データとコンポーネントを組み合わせる

先ほど学んだ `map()` と組み合わせると、さらにすっきり書けます。

```html:src/pages/index.astro
---
import Card from '../components/Card.astro';

const hobbies = [
  { title: "カメラ", description: "週末に風景写真を撮っています。" },
  { title: "登山", description: "低山めぐりが好きです。" },
  { title: "コーヒー", description: "自宅で豆を挽いています。" },
];
---

<html lang="ja">
  <head>
    <meta charset="utf-8" />
    <title>わたしのサイト</title>
  </head>
  <body>
    <h1>わたしのサイト</h1>
    <p>ようこそ！</p>

    {hobbies.map((hobby) => (
      <Card title={hobby.title} description={hobby.description} />
    ))}
  </body>
</html>
```

`title={hobby.title}` のように、文字列の代わりに `{ }` で変数を渡すこともできます。表示結果は先ほどと同じですが、データ（配列）と見た目（コンポーネント）が分離されて、修正しやすくなりました。

内容は自分の趣味や好きなことに書き換えて、自分のプロフィールらしくしてみてください。

## ここで注意：Astroは「ボタンを押したら動く」をそのままは書けない

ReactやVueを知っている方向けの注意です（知らない方は読み飛ばして大丈夫です）。

`.astro` ファイルのコンポーネントスクリプトは**ビルド時に一度だけ実行される**ため、`onClick` のようなイベントハンドラや状態（state）は書けません。「クリックしたら何かが起きる」仕組みが必要な場合は、テンプレート内に `<script>` タグを書きます。これは第11章で扱います。

---

## まとめ

- `.astro` ファイルは「`---` で挟まれたコード部分」と「HTML部分」でできています
- コード部分はビルド時に実行され、ブラウザでは実行されません
- `{ }` で変数を埋め込み、`map()` で繰り返し表示ができます
- コンポーネントは再利用できる部品で、**Props**でデータを渡します
- `<style>` タグのスタイルはそのコンポーネントの中だけに効きます
