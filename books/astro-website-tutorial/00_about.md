## このチュートリアルについて

このチュートリアルでは、**ブログ付きのプロフィールサイト**を作りながら、Webフレームワーク「Astro（アストロ）」の基本的な使い方を学びます。

「自分のサイトを作る」という具体的な目標があると、学習は楽しく進めやすくなります。コードを少しずつ書き加えていくことで、最終的にインターネットに公開できる自分だけのサイトが完成します。

### 完成するもの

チュートリアルを最後まで進めると、次のようなサイトが完成します。

- 自己紹介を載せたトップページとプロフィールページがある
- Markdownで書いた記事が並ぶブログがある
- 記事にタグをつけて、タグごとの一覧ページで絞り込める
- ライトモード／ダークモードを切り替えられる
- GitHub Pagesでインターネットに公開されている

### 前提知識

このチュートリアルは**Astroをはじめて学ぶ方**を対象にしています。以下の知識があると進めやすいです。

- HTMLのタグ（`<div>`、`<p>`など）を見たことがある
- CSSで色や大きさを変えたことがある
- ターミナル（コマンドを入力する黒い画面）を使ったことがある

:::message
ReactやVueなどのフレームワーク経験は**不要**です。Astroは「HTMLとCSSが少し書ければ始められる」フレームワークなので、本格的なプログラミングが初めての方にも向いています。
:::

## Astroとは

[Astro](https://astro.build/) は、コンテンツ中心のWebサイトを作るためのフレームワークです。ブログ、ポートフォリオ、お店や団体の紹介サイト、ドキュメントサイトなど、「情報を見せること」が主役のサイト作りを得意としています。

### Astroの特徴

**1. 表示がとても速い**

Astroは、サイトを公開する前にすべてのページを**ただのHTMLファイル**に変換します（これを**静的サイト生成**と呼びます）。訪問者のブラウザは出来上がったHTMLを受け取るだけなので、表示が速く、スマートフォンでも快適に閲覧できます。

**2. 余計なJavaScriptを送らない**

多くのフレームワークは、ページを表示するために大量のJavaScriptをブラウザに送ります。Astroは「JavaScriptが本当に必要な部分」以外にはJavaScriptを一切送りません。これが表示速度の速さにつながっています。

**3. Markdownとの相性が良い**

ブログ記事などの文章は**Markdown（マークダウン）** という形式で書けます。Markdownは `# 見出し` や `**太字**` のような簡単な記号で文章を装飾できる書き方で、Zennの記事もMarkdownで書かれています。

### なぜプロフィールサイトをAstroで作るの？

プロフィールサイトやブログは、次のような特徴があります。

- 内容は「文章と画像」が中心で、複雑な操作はほとんどない
- 記事を書いたら、あとは見てもらうだけ
- 表示が速いほうが読者にやさしい

これはまさにAstroが得意とする領域です。「コンテンツが主役のサイトはAstroで作る」というのは、現在のWeb制作でよく使われる選択肢のひとつになっています。

## 使用する技術

| 技術 | 役割 |
|---|---|
| Astro | サイトの構築・ページ生成 |
| HTML / CSS | ページの構造と見た目 |
| Markdown | ブログ記事の執筆 |
| TypeScript | 設定ファイルなどでの型安全な記述（最小限） |
| GitHub Pages | サイトの公開 |

:::message
TypeScriptという言葉が出てきましたが、身構える必要はありません。このチュートリアルで書くコードのほとんどはHTMLに近い書き方で、TypeScriptらしいコードが登場するのは設定ファイルなどごく一部です。登場するたびに丁寧に説明します。
:::
