title: この本について

この本では「なんでも図鑑カードメーカー」という Web アプリを動かしながら、プログラムから AI を使うしくみを学びます。

言葉を1つ入れると、AI がその言葉の図鑑データを作り、カードにして画面に表示します。たとえば「たこ焼き」と入れると、「なまえ」「ぶんるい」「つよさ」「かわいさ」「せつめい」が並んだカードができあがります。

<!-- 画像: カードが表示された画面 -->

AI には、さくらインターネットが提供する「さくらのAI Engine」の API（プログラムから AI を呼び出すための窓口）を使います。

## この本でできるようになること

- プログラムから AI にデータを送り、答えを受け取るしくみがわかる
- AI に送ったデータと返ってきたデータを、自分の目で確かめられる
- 設定ファイルを書き換えて、AI への頼み方やカードの項目を変えられる
- AI の答えをそのまま使わず、チェックしてから使う理由がわかる

プログラミングの経験がなくても進められるように書いています。プログラムを一から書く場面はなく、用意された設定ファイルを書き換えて、結果がどう変わるかを見ていきます。

## 必要なもの

| 必要なもの | 用途 | 準備する章 |
|---|---|---|
| パソコンとブラウザ | 作業はすべてブラウザの中で行います。ソフトのインストールは不要です | - |
| GitHub のアカウント | 教材をコピーし、Codespaces（ブラウザで使える作業場所）を動かします | 3章 |
| さくらインターネットの会員ID | さくらのAI Engine を使うためのキー（トークン）を発行します | 2章 |
| クレジットカードと電話 | さくらのAI Engine の利用登録で、本人確認とカード登録が必要です | 2章 |

## お金はかかるのか

この本の範囲なら、無料で進められます。

- **さくらのAI Engine**：無償プランを使います。チャット（文章を作る機能）は毎月3,000回まで無料です。上限に達しても、その月はそれ以上使えなくなるだけで、料金は発生しません。ただし、利用登録のためにクレジットカードの登録が必要です
- **GitHub Codespaces**：無料プランでも、毎月一定の時間まで無料で使えます。くわしくは3章で説明します

この本を最後まで進めても、AI を呼ぶ回数は数十回ほどです。

## 進め方

2章から9章までは、順番に進めてください。前の章で設定したものや、作ったカードを使って次の章に進みます。

| 章 | 内容 |
|---|---|
| 2章 トークンを手に入れる | さくらのAI Engine に登録し、AI を使うためのキーを発行する |
| 3章 準備 | 自分のリポジトリを作り、Codespaces を起動する |
| 4章 動かす | キーを設定してカードを1枚作る。キーを人に見せてはいけない理由 |
| 5章 中をのぞく | AI に送ったもの・返ってきたものを見る。API とは何か |
| 6章 カードを変える | カードの項目を足す・消す・名前を変える |
| 7章 ルールと temperature | AI へのルールを足す。答えのバラつきを変える |
| 8章 壊れた返事 | AI の返事が使えなくなる様子を見る。チェックとやり直しの意味 |
| 9章 発展 | デザインを変える、モデルを比べる、対戦機能を作る など |
| 10章 困ったときは | よくあるつまずきと対処のまとめ |

うまくいかないときは、まず10章を見てください。

## ファイルの地図

教材のリポジトリには、いくつかのファイルが入っています。この本で触るのは、次の表で「★」がついたものだけです。

| ファイル | 触ってよいか |
|---|---|
| `config.js` | ★ 書き換えてOK（カスタマイズの中心） |
| `.env` | ★ キーを貼る（人に見せない） |
| `public/index.html`、`public/style.css` | ★ 9章の発展課題で書き換えてOK |
| `server.js`、`src/`、`public/app.js` | 読むだけでOK |
| それ以外 | 触らなくてOK |
