title: 困ったときは
---

この章では、よくあるつまずきと、その直し方をまとめます。ターミナルやブラウザの画面に出た文言で探してください。

## キー（.env）に関するもの

| 症状 | 原因 | 対処 |
|---|---|---|
| ターミナルに【まだ .env ファイルがありません】と出る | `cp .env.example .env` を実行していない。または `.env.example` に直接キーを貼った | ターミナルで `cp .env.example .env` を実行し、できた `.env` にキーを貼り直す（4章） |
| ターミナルに【.env にキーが入っていません】と出る | キーを貼ったあとに保存していない | `.env` を保存し、Ctrl + C で止めてから `npm start` |
| ターミナルに【注意】キーの形がいつもと違うようです と出る | キーの前後に空白がある、`"` で囲んだ、`:` の後ろを貼り忘れた | `.env` の1行を `SAKURA_AI_TOKEN=キー` の形に直す |
| 画面に「キーが正しくないようです」と出る | キーの写し間違い。一覧画面の UUID だけを貼った。トークンを削除した | 控えておいたキーを全体で貼り直す。見つからないときは、新しいトークンを作る（2章） |

キーを控えたメモをなくしたときは、あとから見る方法はありません。2章の手順で新しいトークンを作り、古いトークンは削除してください。

## サーバーや画面に関するもの

| 症状 | 原因 | 対処 |
|---|---|---|
| `config.js` を変えても画面が変わらない | ブラウザを再読み込みしていない | F5（Mac は Cmd + R）で再読み込みする |
| ターミナルに【config.js の書き方に間違いがあります】と出る | カンマやかっこの書き間違い | 案内の行番号か、その1つ前の行を直し、Ctrl + C → `npm start`（直して保存しても自動では起動し直さない）（6章） |
| ターミナルに【ポート 3000 がすでに使われています】と出る | 別のターミナルで `npm start` が動いている | 動いているほうのターミナルで Ctrl + C を押して止める |
| 画面に「サーバーにつながりませんでした」と出る | サーバーが止まっている | ターミナルで `npm start` |
| 画面に「混み合っています」と出る | 短時間に呼びすぎた。または、無償プランの月間上限（3,000回）に達した | 少し待ってから試す。続くときは、さくらのAI Engine のコントロールパネルで利用状況を確かめる |
| 画面に「AI が受け付けてくれませんでした」と出る | `config.js` の `model` の名前が違う | 名前を確認する。わからなければ `gpt-oss-120b` に戻す（9章） |
| ブラウザのタブが自動で開かない | 設定やブラウザの都合で開かないことがある | ターミナルの上の「ポート」タブで、3000 の行の地球のマークを押す（4章） |

## Codespaces に関するもの

| 症状 | 原因 | 対処 |
|---|---|---|
| Codespaces の画面が反応しない・止まっている | 30分操作しなかったので自動で止まった | ブラウザのタブを再読み込みするか、リポジトリのページの「Code」→「Codespaces」から開き直す。開き直したら `npm start` を実行する |
| Codespaces が起動できない | 無料プランの月間上限に達した | 翌月まで待つ。使わなくなった Codespace は削除しておく（3章） |
| ターミナルが見当たらない | 閉じてしまった | 画面左上の「≡」→「ターミナル」→「新しいターミナル」 |

## ポートの公開範囲に気をつける

Codespaces の「ポート」タブでは、3000 番ポートの公開範囲を変えられます。はじめは Private（自分だけが開ける）になっているので、そのままにしてください。

Public に変えてしまうと、URL を知った他人があなたのアプリを開けるようになります。アプリはあなたのキーで AI を呼ぶので、他人があなたの利用回数を使えてしまいます。

うっかり変えてしまったときは、「ポート」タブで 3000 の行を右クリックし、「ポートの表示範囲」→「Private」に戻してください。

## それでも直らないときは

- ターミナルの表示をよく読みます。このアプリは、よくある間違いには日本語で案内を出すように作ってあります
- 9章の最後の「元に戻したくなったら」の手順で、書き換えたファイルを元に戻します
- それでもだめなら、3章の手順でリポジトリと Codespace を作り直します

## 使い終わったら

この本を終えて、もうアプリを使わないときは、次の2つをしておくと安心です。

1. さくらのAI Engine のコントロールパネルで、この本のために作ったアカウントトークンを削除する（2章）
2. GitHub で、使わなくなった Codespace を削除する（3章）

おつかれさまでした。この本で見た「API にデータを送り、返ってきた答えをチェックしてから使う」という流れは、ほかの AI サービスを使うときにもそのまま役立ちます。
